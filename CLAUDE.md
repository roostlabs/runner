# runner

Процес на VPS дева. Go, модуль `github.com/roostlabs/runner`.

Ширший контекст — `../.github-private/PROJECT_CONTEXT.md` (архітектурні рішення)
і `../.github-private/roadmap.md` (фази). Контракт каналу — `../protocol/PROTOCOL.md`.
Прочитай перед змінами.

## Правила цього репо

- **Креди не йдуть угору.** Ніколи. У Cloud — лише булеві прапорці (`cred.status`).
  Значення живуть у конфізі (`0600`) і потрапляють у sandbox як env на час задачі.
  `cmd_output` перед відправкою чиститься через `config.Creds.Values()`.
- **Спочатку журнал, потім стрім.** Подія пишеться в event-store і лише потім
  йде в канал. Інакше обрив каналу = втрачена історія.
- **Агент виконує код лише в контейнері.** Ніколи на хості. Ліміти `--cpus`/
  `--memory` обов'язкові.
- **Concurrency = 1** за замовчуванням. Цільова тачка — 1 CPU / 2GB.
- **Обрив каналу — норма, не помилка.** Задача продовжує працювати. Реконект з
  backoff + jitter. Не роби graceful-close на мертвому з'єднанні: бібліотека
  чекає close-frame 5 секунд — використовуй `CloseNow()`.
- **Невідомий `type` ігнорується мовчки**, ніколи не reject.
- Залежності — тільки cgo-free (бінарник має лишатись статичним для інсталера).
  Зараз їх дві: `coder/websocket`, `modernc.org/sqlite`. Нову додавай лише за
  вагомої причини.
- Публічний репо — коментарі й документація англійською.
- Не пиши заглушку, що вдає роботу. Нереалізоване — відповідай чесною помилкою
  (див. `handleTaskRun`).

## Перевірка перед комітом

```bash
gofmt -l . && go vet ./... && go test -race ./...
```

## Залежність від protocol

`go.mod` має `replace github.com/roostlabs/protocol => ../protocol` для швидкої
ітерації. Коли протокол устоїться — прибрати `replace` і залежати від тега.
